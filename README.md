# QuestPass CR

## Descripción del proyecto

QuestPass CR es una página web desarrollado como parte de un proyecto
académico de la materia de Diseño y Programación web. 

El objetivo es presentar diferentes experiencias turísticas que se pueden realizar en
Costa Rica, esto mediante una interfaz que permita consultar información
sobre las actividades y reservar si los usuarios lo desean.

Este primer avance esta enfoca en la estructura HTML, el diseño
visual con CSS y la adaptación de las páginas a diferentes
tamaños de pantalla.

## Tecnologías utilizadas

- HTML5: estructura y contenido de las páginas.
- CSS3: diseño y presentación visual.
- Flexbox: organización de elementos y navegación.
- CSS Grid: distribución de contenido.
- Media Queries: adaptación a dispositivos móviles.

## Descripción de las páginas

### index.html
Página principal donde se presenta QuestPass CR y permite
navegar hacia las demás secciones.

### experiencias.html
Muestra un catálogo de seis experiencias turísticas disponibles
en Costa Rica.

### detalle.html
Presenta información detallada de la experiencia QST-001.

### reservar.html
Muestra el ormulario para solicitar una reserva.

### contacto.html
Permite enviar un formulario de contacto.

### login.html
Presenta la interfaz de inicio de sesión.

### admin.html
Muestra el panel administrativo con una tabla de experiencias y la opción de reservar.

## Cómo ejecutarlo

1. Clonar el repositorio desde GitHub.
2. Abrir la carpeta.
3. Localizar el archivo index.html.
4. Abrir index.html en un navegador web.
5. Utilizar el menú de navegación para visitar las diferentes páginas.


## Funcionalidades implementadas

- Navegación entre las siete páginas HTML.
- Visualización de experiencias turísticas.
- Página de detalle de una experiencia.
- Formulario de reservas con validaciones HTML5.
- Formulario de contacto.
- Interfaz visual de inicio de sesión.
- Panel administrativo con tablas.
- Diseño adaptable a diferentes tamaños de pantalla.

## Limitaciones del primer avance

- No almacenan información.
- En inicio de sesión la autenticación no es funcional.
- El panel administrativo es únicamente visual.
